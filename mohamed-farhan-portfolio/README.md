# Mohamed Farhan P — Portfolio

## Run locally
Open `index.html` with Live Server or any local static server. Keep `styles.css`, `script.js`, and the `assets` folder beside it.

## Deploy
Upload the contents of this folder to Netlify, Vercel, or another static host. Ensure `index.html` is at the publish root.

## Themes
Use the LIGHT/DARK control in the navigation. The light theme now uses warm ivory surfaces, white cards, forest-green accents, and a dark contact section; the dark theme uses charcoal surfaces and cyan accents. The selected theme is remembered in the browser.
